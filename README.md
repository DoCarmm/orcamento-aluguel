# Orçamento de Aluguel - Imobiliária R.M.

Projeto desenvolvido em Python para automatizar a geração de orçamentos de locação da Imobiliária R.M.

## Funcionalidades

- Cadastro dos dados do cliente
- Seleção entre Apartamento, Casa e Estúdio
- Cálculo automático do aluguel
- Aplicação de adicionais de quartos e garagem
- Aplicação de desconto para apartamentos
- Parcelamento do contrato imobiliário
- Geração das 12 parcelas do orçamento
- Exportação dos dados para arquivo CSV

## Tecnologias utilizadas

- Python
- Programação Orientada a Objetos
- Biblioteca CSV
